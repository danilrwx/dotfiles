# Loop / Mattermost

Paper uses the desktop's light palette: #f2e8d2 background, #33322e text,
warm gray selections, muted olive presence and terracotta notifications.

For the full palette, open Settings > Display > Theme > Custom theme and paste
paper.json into the field for sharing theme colors, then save.

paper-slack.txt is the eight-color string for Import theme colors from Slack.
That import covers only part of the theme; use the JSON to color message areas too.

These are manual imports. The desktop's x-theme command does not change Loop's
account preferences. Code highlighting uses Mattermost's built-in github theme.

Format: https://github.com/mattermost/mattermost/blob/master/docs/main/end-user-guide/preferences/customize-your-theme.mdx
