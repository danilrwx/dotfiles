# Foot

The current trial uses Fixedsys Excelsior at 17.5 pixels without
antialiasing. Bold uses the regular face. Missing icons fall back to IosevkaTerm
Nerd Font Mono. Ctrl++ / Ctrl+- changes size by 0.5 logical pixels; Ctrl+0 resets it.

Fixedsys is installed locally under ~/.local/share/fonts/fixedsys from:
https://github.com/kika/fixedsys/releases/tag/v3.09.10
The base installer does not install this trial font.

Previous font: PT Mono:pixelsize=18.
